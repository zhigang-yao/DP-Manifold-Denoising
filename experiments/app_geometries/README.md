# Appendix: additional geometries

This case uses the frozen experiment drivers in `experiments/_shared/` and the algorithm in `modules/`. The final paper figure/table assets are under `results/app_geometries/`. Numerical settings and seeds are those of the frozen campaign (2026-11-20), in which the public queries are redrawn for every reference repetition.

Run: `uv run python reproduce.py --case app_geometries`. To regenerate plots from the archived unit store, use `uv run python reproduce.py --plots`.
